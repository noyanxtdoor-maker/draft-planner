--- D. Contact transition/flicker fix -----------------------------------------
FILE: lib/features/contacts/data/drift_contact_repository.dart
OWNER ITEM: D
EXACT CHANGE: readTimeline() freeze writes now run in ONE transaction (drift
  emits one coalesced table update instead of one per occurrence) AND each
  freeze participant write is guarded by an existence check (SELECT-before-
  INSERT).  Root cause: the read ran inside a provider watching
  eventOccurrenceParticipants updates, so every mid-read freeze write
  re-triggered the read - a ~5Hz loading<->data flicker cascade with
  unbounded row growth (fresh UUID per write).  Both changes make the
  follow-up read a pure no-op.
INHERITED OR NEW: NEW

FILE: lib/features/contacts/presentation/contact_detail_screen.dart

EXACT CHANGE: the detail build retains the last valid ContactDetail while a
  refresh is in flight (detailAsync.value); the loading/error scaffolds now
