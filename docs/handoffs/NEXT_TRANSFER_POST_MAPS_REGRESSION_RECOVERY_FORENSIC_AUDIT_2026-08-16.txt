4. MP-04 — LIVE PREVIEW-DATE ACCENT: ROOT CAUSE = SCREEN-SPACE CLIPPING
================================================================================
CLASSIFICATION: MP04_CLIPPED_TRUE_LEFT_EDGE (matches the owner's frame
evidence exactly).

CODE TRUTH: the accent is painted synchronously with the block — a 3dp
BorderSide on a DecoratedBox inside the preview Material (normal events,
planner_interactive_day_pager.dart ~1435) or the striped 3dp SizedBox
(PlannerBackupStripeBackground, backup events). The widget-tree test
(mp04_live_transition_border_test.dart) passes because it asserts BorderSide
presence, not screen-space visibility.

SCREEN-SPACE TRUTH (owner recording, 30fps transition ~31.9-32.1s): during a
held/partial horizontal pager slide, the incoming day column is translated
inside a ClipRect (planner_interactive_day_pager.dart lines 926-950). A
wide/full-lane Event's true left edge remains outside the viewport while its
body is already visible → the accent (painted at the block's own left edge) is
clipped offscreen with it. Narrower right-lane Events whose own left edge
already entered the viewport DO show their accent — consistent with the
frames. The old test was testing the wrong invariant.

REQUIRED CONTRACT (owner): for ANY visible preview Event fragment, an accent
must be visible at the fragment's visible left boundary in the SAME frame;
when the true left edge enters, no double accent / no pop; settled rendering
unchanged; both swipe directions; backup stripes included.

FIX DESIGN (preview-only, no pager/lane/timing change):
- New widget PlannerPreviewFragmentAccent (CustomPaint) wrapping the preview
  event body. Its painter reads canvas.getClipBounds() in local space; when
  clipLeft > accentWidth (true accent fully clipped) AND a fragment is visible
  (clipLeft < width), it paints an accent strip at x = clipLeft (solid accent
  for normal; the approved dark+accent stripe pattern for backup). When
  clipLeft <= accentWidth the true accent is (partially) visible and nothing
  extra is painted — no double accent, no pop on settle. Settled state
  (clipLeft <= 0) paints nothing — zero settled delta.
- Applied ONLY to _positionedPreviewEvent in planner_interactive_day_pager.dart.
- canvas.getClipBounds() is available on Flutter 3.44 (added 3.13).
